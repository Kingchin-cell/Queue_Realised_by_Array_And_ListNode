队列 C++多态实现
 
介绍
 
利用抽象基类+虚函数实现多态，同一套调用接口，支持数组队列、链表队列两种写法，底层实现互不干扰。
 
文件结构
 
- QueueBase 抽象基类
- ArrayQueue 数组循环队列
- LinkQueue 链式队列
- main 测试程序
 
特点
 
1. 接口统一，调用方式完全一致
2. 数组队列定长高效，链表队列动态无上限
3. 虚析构函数，内存安全释放
4. 轻松切换两种队列结构
 
使用
 
父类指针指向子类对象，直接调用队列增删查空判满等功能，无需修改业务代码即可切换底层结构。
 
运行环境
 
Visual Studio 2022，标准C++语法
